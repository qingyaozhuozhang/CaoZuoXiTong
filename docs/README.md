本地生成的日志与报告放入 `artifacts/`；[test 功能包](../test/README.md) 将 GitHub 最新一轮结果同步至 `test/results/`，每轮仅替换结果，不改写包代码。`archive/` 保存随仓库提交的固定验证报告，供离线复核；过期的开发快照可从 Git 历史追溯。引用结果时应同时给出源码版本、工作树状态、环境、命令及跳过项目。

阅读结果时先看“双架构 CI 验证汇总报告”，再看各作业的“功能、正确性与性能验证报告”；getpid 基准和 A3 合流分别提供专项报告。[报告路径与范围](testing.md#8-报告名称与阅读顺序) 说明每份材料能支持的结论。当前新增的连续完整清理门禁、真实合流和独立 exec 验证需要新一轮 CI；`3ffd736` 归档保留当时口径，不改写为新版验收结论。
